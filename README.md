# 데일리카네기 (Daily Carnegie) 웹사이트

"매일 만나는 카네기 교육" — 데일카네기코리아(바인그룹)의 **최고경영자(CEO) 과정** 안내·입학 상담 사이트입니다.
서비스명은 **데일리카네기**, 교육 과정 내용은 **데일카네기** 표기를 사용합니다.
순수 HTML / CSS / JavaScript로 작성되어 별도 빌드 과정 없이 바로 배포됩니다.

## 페이지 구성

| 파일 | 내용 |
|------|------|
| `index.html` | 홈 (히어로 + 모집 기수 카드, 선택 이유, 4대 프레임워크, 12주 요약, 수치, 특전, 후기, CTA) |
| `program.html` | 과정 소개 (개요, 목표, 12주 커리큘럼, 6가지 특징, 기대 효과, 수료 특전) |
| `about.html` | 데일카네기 소개 (철학, 글로벌 수치, 연혁 타임라인, 3대 프로그램, 고객사) |
| `alumni.html` | 카네기클럽 동문 네트워크 + 수료 후기 |
| `faq.html` | 자주 묻는 질문 (아코디언, FAQ 구조화데이터) |
| `apply.html` | 개강 일정표, 수강료, **입학 상담 신청 폼** |
| `privacy.html` | 개인정보처리방침 |

## 로컬 미리보기

```bash
python -m http.server 8800
# http://localhost:8800
```

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 1~2분 뒤 자동 배포됩니다. (빌드 없음 / 루트 디렉터리)

## 상담 폼 연동

`apply.html`의 폼은 다른 사이트(과외·픽포스)와 같은 공용 Apps Script 웹앱으로 전송되어 구글 "웹 문의" 시트에 저장됩니다 (구분: 데일리카네기-입학상담).
전용 탭으로 분리하려면 `google-apps-script.gs`를 새 웹앱으로 배포하고 `data-sheet` URL만 교체하면 됩니다.
